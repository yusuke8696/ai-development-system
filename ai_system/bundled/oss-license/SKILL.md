# OSSライセンスの選定ルール

プロジェクトの許可リストでONのSPDX IDだけを使用する。ライセンスが不明、許可リストにない、複合ライセンスの条件を判断できない場合は導入せず、代替候補を探すかユーザーへ確認する。ユーザーの回答だけで許可リストを変更したことにしない。変更は設定と登録PRの確認を通す。

直接依存と推移的依存のライセンスを確認する。依存関係の宣言とロックファイルを保存し、取得元、版、ライセンス、著作権表示やNOTICEの必要性を文書に記録する。コードやライブラリの転載、CDN、vendoringにも同じ許可リストを適用し、スキャナーが検出しないから許可されたとは判断しない。

osv-scannerとGitHub Actionsの検証結果を確認する。未実施・取得失敗・ライセンス不明を合格と記載しない。ポリシー、検査スクリプト、workflowの削除・無効化・ignore設定で検査を回避しない。AIからGitHubのマージや人の承認を代行しない。
